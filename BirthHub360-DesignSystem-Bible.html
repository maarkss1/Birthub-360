Design System Bible — Definitive Documentation

Generated: September 25, 2026 | Version: 1.0

📋 Overview

Birth Hub 360° is an enterprise CRM with AI for high-performance commercial teams. This design system documentation is based on real application runtime, screenshots, DOM measurements, and source code analysis.

Design Philosophy

Theme: "Strategic Command Center" — A gold-accented, enterprise-focused design system with strategic color palette.

Technical Stack

  • React 19 Frontend framework
  • Tailwind CSS 4 Utility-first CSS
  • Framer Motion Animations
  • TypeScript Type safety
  • Vite Build tool

Design Tokens Source

Primary design tokens are defined in src/styles/globals.css with CSS custom properties for both light and dark themes.

Font Loading

All fonts are self-hosted in public/fonts/ for offline capability (Android Capacitor app). Only IBM Plex Mono tabular numbers are loaded via Google Fonts CSS2.

Responsive Behavior

The application uses a mobile-first approach with responsive breakpoints handled through Tailwind CSS 4. The sidebar collapses to a drawer on mobile, and grid layouts adjust based on available screen width.

⚠️ Inconsistencies

Based on the analysis, here are identified inconsistencies in the design system:

Font Loading Issue

During automated extraction, the application showed Times New Roman as the default font, indicating potential font loading delays or fallback issues in certain contexts.

Screenshot Capture Failure

Tablet portrait (768 × 1024) viewport failed to capture screenshots in some instances due to browser protocol limitations.
