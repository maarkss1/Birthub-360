🔒 Segurança

Autenticação

  • Better Auth: Biblioteca de autenticação com suporte a e-mail/senha e OAuth (Google, Microsoft)
  • Sessão: Cookie-based session com better-auth.session_token
  • Middleware: authenticateToken valida sessão em rotas protegidas

Autorização (RBAC)

  • Papéis Hierárquicos: ADMIN (100) > GESTOR (75) > CLOSER (50) > SDR (40) > VISUALIZADOR (10)
  • Middleware: requireRole verifica permissões por rota
  • Multi-tenant: requireTenant isola dados por organização
  • Fonte Canônica: src/lib/auth/authorization.ts

Segurança de Dados

  • PII Encryption: Campos sensíveis (email, phone, whatsapp) cifrados em repouso (AES-256-GCM)
  • Blind Index: Índices HMAC-SHA256 para busca em dados cifrados
  • Secrets Encryption: Credenciais de integrações cifradas com chave dedicada
  • RLS: Row Level Security no PostgreSQL para isolamento de tenant

Rate Limiting

  • API Rate Limit: 600 requisições/15min por IP (configurável)
  • AI Rate Limit: 30 requisições/15min por organização
  • Auth Rate Limit: 20 requisições/15min para rotas de auth
  • Redis-backed: Rate limiting distribuído via Redis

Outros Mecanismos

  • Helmet: Headers de segurança HTTP
  • CORS: Configurável via ALLOWED_ORIGINS
  • CSRF Protection: Via middleware csrfGuard
  • Secret Scanning: Gitleaks no CI/CD
src/lib/auth/, src/bootstrap/security.ts, src/bootstrap/rateLimiters.ts

🚀 Deploy

  • Workflow Principal: .github/workflows/ci.yml
  • Gates: Secret scan → Lint → Typecheck → Unit tests → Integration tests → E2E → Build

Build

  • Backend: esbuild bundling para Node.js
  • PWA: Service worker com cache strategies
