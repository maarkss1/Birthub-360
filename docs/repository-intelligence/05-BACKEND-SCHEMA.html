🗄️ Database Schema

PostgreSQL + pgvector

Banco de dados PostgreSQL com extensão pgvector para embeddings e busca vetorial. Suporta RLS (Row Level Security) para isolamento multi-tenant.

🔒 Security

Autenticação

  • Better Auth: Biblioteca de autenticação com suporte a e-mail/senha e OAuth
  • Session: Cookie-based session com better-auth.session_token
  • Middleware: authenticateToken valida sessão em rotas protegidas

Autorização (RBAC)

  • Hierarquia: ADMIN (100) > GESTOR (75) > CLOSER (50) > SDR (40) > VISUALIZADOR (10)
  • Middleware: requireRole verifica permissões por rota
  • Multi-tenant: requireTenant isola dados por organização
  • Fonte Canônica: src/lib/auth/authorization.ts

Segurança de Dados

  • PII Encryption: email, phone, whatsapp cifrados (AES-256-GCM)
  • Blind Index: Índices HMAC-SHA256 para busca em dados cifrados
  • Secrets Encryption: Credenciais de integrações cifradas
  • RLS: Row Level Security no PostgreSQL

Rate Limiting

  • API Rate Limit: 600/15min por IP
  • AI Rate Limit: 30/15min por organização
  • Auth Rate Limit: 20/15min para rotas de auth
  • Redis-backed: Rate limiting distribuído

Headers de Segurança

  • Helmet: Headers de segurança HTTP
  • CORS: Configurável via ALLOWED_ORIGINS
  • CSRF: Proteção via csrfGuard
src/lib/auth/, src/bootstrap/security.ts, src/bootstrap/rateLimiters.ts
