🎨 Visão Geral do Design System

Framework CSS

TailwindCSS 4.1.14 com @tailwindcss/vite plugin. Design system "Strategic Command Center" (setembro 2026) com paleta renovada e tipografia variável.

Características Principais

  • Tema Dark/Light: Suporte completo com tokens CSS customizados
  • Tipografia Variável: Cabin (display) e IBM Plex Mono (body/código)
  • Paleta Brand: Midnight Blue, Sunset Orange, Red-Violet, Gold, White
  • Motion: Framer Motion para animações respeitando prefers-reduced-motion
  • Responsivo: Mobile-first com breakpoints Tailwind

  • Tables: Striping com hover states e ações inline

♿ Acessibilidade

WCAG AA Compliance

  • Contraste: Todos os tokens de cor calibrados para mínimo 4.5:1 (AA)
  • Focus Visible: Estados de focus visíveis em todos os elementos interativos
  • Reduced Motion: Framer Motion com reducedMotion="user"
  • Screen Readers: ARIA labels em componentes interativos
  • Keyboard Navigation: Navegação completa via teclado

Ferramentas de QA

  • @axe-core/playwright: Testes automatizados de acessibilidade
  • eslint-plugin-jsx-a11y: Lint estático para acessibilidade React
  • Playwright a11y: Suíte E2E específica para acessibilidade
tests/e2e/accessibility.spec.ts, .github/workflows/playwright-ci.yml

Contraste Calculado

Todos os tokens de cor foram calculados usando fórmula de luminância relativa do WCAG, não estimados. Tokens ativos (texto sobre superfície) garantem mínimo 4.5:1 em ambos os temas.

src/styles/globals.css (comentários de cálculo de contraste)

📱 Responsividade

Breakpoints Tailwind

  • sm: 640px (mobile landscape)
  • md: 768px (tablet)
  • lg: 1024px (desktop)
  • xl: 1280px (desktop large)
  • 2xl: 1536px (desktop extra large)

Mobile Optimization

  • Capacitor: Android/iOS wrapper com server.url
  • PWA: Service worker com cache strategies
  • Touch Targets: Mínimo 44px para elementos interativos
  • Bottom Navigation: Dock flutuante para mobile
