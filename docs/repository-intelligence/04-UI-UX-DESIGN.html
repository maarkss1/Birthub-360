1. Design System Overview

The AtlasGR interface is built using React, Tailwind CSS, and shadcn/ui. It emphasizes a clean, enterprise-grade data-dense design optimized for B2B operations.

2. Core Technologies

Technology Usage
Tailwind CSS Utility-first styling, design tokens, responsive breakpoints, dark/light mode execution.
shadcn/ui Accessible, customizable baseline components (Buttons, Inputs, Dialogs, etc.).
Lucide React Consistent SVG iconography across the platform.
TanStack Table Complex, sortable, paginated data grids for CRM and lead lists.

3. Component Inventory (Sample)

Toasts / Notifications IMPLEMENTADO +
Location: src/lib/toast.ts
Usage: Non-blocking user feedback (toast.success, toast.error). Replaces all native alert() calls.
Data Tables IMPLEMENTADO +
Usage: CRM Lead lists, Activity logs. Built heavily on TanStack Table for headless UI state management, styled via Tailwind.

4. ID Generation Security

Frontend unique ID generation strictly utilizes crypto.randomUUID() to ensure cryptographic safety and collision resistance, expressly avoiding weak implementations like Math.random().
