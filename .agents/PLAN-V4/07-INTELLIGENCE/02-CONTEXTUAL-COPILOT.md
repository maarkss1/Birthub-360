# Contextual Copilot

O Copilot não deve ser apenas uma tela de chat.

### Dentro de CRM

Pode responder:

- Quem é essa conta?
- O que aconteceu?
- Qual risco?
- Qual próxima ação?
- Gere uma mensagem.
- Atualize o registro.
- Prepare a reunião.

### Dentro de Prospecção

Pode responder:

- Essa empresa tem fit?
- Quem abordar?
- Como abordar?
- Qual cadência?
- Priorize minha lista.

### Dentro de gestão

Pode responder:

- O que mudou?
- Onde está o risco?
- Quais oportunidades precisam de atenção?
- Quais ações devem ser delegadas?

O Copilot é a interface humana do Intelligence Engine.
