# Experience Layer vs Engine Layer

## Experience Layer — o que o cliente compra

```text
Birth Hub 360º
│
├── CRM Comercial
├── Prospecção Inteligente
└── Copiloto Comercial IA
```

## Engine Layer — o que sustenta o produto

```text
Intelligence
Agents
Capabilities
Automation
Governance
RAG / Knowledge
Integrations
Workers / Queues
Events
Security
Observability
Infrastructure
```

### Princípio

Engine não deve criar navegação automaticamente.

A pergunta é:

> "Essa capacidade melhora uma tarefa do usuário ou apenas demonstra que o sistema possui tecnologia?"

Se a resposta for apenas tecnologia, ela permanece atrás da interface.
