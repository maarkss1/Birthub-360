# Capability Taxonomy

Toda capability existente deve ser classificada como:

## A — Core Product

CRM, Prospecção, Copiloto.

## B — Contextual Capability

BI, forecast, playbooks, roleplay, gamification, enrichment, scoring, communications.

## C — Intelligence Engine

Agents, RAG, memory, AI gateway, guardrails, swarm.

## D — Automation Engine

Jobs, queues, workflows, triggers, scheduling.

## E — Integration

Bitrix24, WhatsApp, 3CX/Birth Voices, Google e demais conectores.

## F — Governance/Admin

RBAC, tenant controls, audit, AI governance, security.

## G — Infrastructure

Postgres, pgvector, Redis, workers, observability, CI/CD.

### Regra

A existência de uma capability não implica a existência de um item de navegação.
