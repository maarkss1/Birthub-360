# ML Scoring Target

PostgreSQL
→ dataset
→ feature engineering
→ leakage validation
→ train/test
→ XGBoost/Random Forest
→ evaluation
→ model registry
→ `/api/intelligence/scoring`
→ score + factors + confidence + recommendation/action
→ drift monitoring.

Metrics:

- Precision;
- Recall;
- F1;
- ROC-AUC;
- feature importance;
- calibration/confidence when appropriate.
